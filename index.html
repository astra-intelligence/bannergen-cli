🖼️ BannerGen

AI-powered social media banner generator — from your terminal.

CLI Python Open Source MIT

📐 Platform-Aware

Twitter/X, LinkedIn, Instagram, YouTube, Facebook — correct dimensions every time.

🎨 Style System

Modern, Minimal, Bold, Elegant, or Fun — one flag for completely different looks.

🏷️ Brand Overlay

Your brand name + tagline automatically positioned on the final image.

📦 Batch Mode

Generate 50 banners from a text file in one command.

Quick Start

$ pip install bannergen-cli
$ export FAL_KEY="your-key"
$ bannergen generate "Modern tech office with city view" --platform linkedin --brand "Acme Corp"
